# هاشم خالد شطير — الموقع الأدبي الرسمي


🌐 **الموقع المنشور للزوار:** https://hashem-shatir-literary.prettybard17.chatgpt.site

> ملاحظة: GitHub يحفظ الكود وإصداراته، بينما الموقع المباشر مستضاف على Sites/Cloudflare. رفع تعديلات إلى هذا المستودع لا ينشرها تلقائيًا على الموقع المباشر.

موقع عربي تفاعلي للكاتب والروائي اليمني **هاشم خالد شطير**، يعرض مؤلفاته ويسمح بقراءتها وتحميلها ويحتوي على مدونة وآراء القرّاء ولوحة إدارة محمية.

> هذا المستودع نسخة من **الكود المصدري للموقع**، وليس نسخة احتياطية تلقائية من تعليقات القرّاء أو البيانات الحية. البيانات الحية محفوظة في Cloudflare D1 والملفات المرفوعة لاحقًا في R2 المرتبطين بالموقع.

## ما الذي يتضمنه المشروع؟

- واجهة عربية `RTL` بتصميم داكن وذهبي، متجاوبة مع اللابتوب والجوال.
- مكتبة كتب مع بحث وتصنيفات ومعاينة تفاعلية ثلاثية الأبعاد.
- صفحات تفصيلية لكل كتاب ومعرض للأغلفة الأصلية.
- قارئ صفحات عربية عالية الدقة (WebP) من ملفات PDF الأصلية، مع التكبير والوضع الليلي وحفظ موضع القراءة، وتنزيل PDF الأصلي.
- صفحة «مكتبتي» لعرض تقدّم القراءة محليًا ووضع علامة «مكتمل».
- سيرة الكاتب واقتباساته ومدونة أدبية.
- تقييمات القراء مع مراجعة إدارية قبل النشر.
- لوحة إدارة لإضافة كتب جديدة ورفع أغلفتها وملفات PDF، وتحرير المؤلفات والمقالات والمراجعات.

## تشغيل محلي للمطورين

تحتاج **Node.js 22.13 أو أحدث** وGit. افتح Terminal داخل مجلد المشروع وشغّل:

```bash
corepack enable
pnpm install --frozen-lockfile
npm run dev
```

رابط المعاينة المحلية سيظهر في الـTerminal. أثناء التطوير المحلي، العمليات التي تحتاج قاعدة البيانات أو هوية المشرف تتطلب إعداد بيئة Cloudflare التجريبية؛ مجرد تشغيل الواجهة لا يمنحك صلاحيات الإدارة الحية.

للتحقق من TypeScript وبناء المشروع:

```bash
npx tsc --noEmit --incremental false
npm run build
```

### تغيير قاعدة البيانات

إذا عدّلت `db/schema.ts`، نفّذ `npm run db:generate` لإنشاء **ملف migration جديد**. لا تعدّل migrations سبق نشرها. عند نشر النسخة عبر Sites تُطبّق الترقيات الجديدة على قاعدة البيانات المستضافة.

### تفعيل حساب المشرف

لوحة الإدارة في `/admin` مقفلة تلقائيًا حتى يتم تعيين متغير الخادم:

```text
SITE_ADMIN_EMAILS=authorized-admin@example.com
```

يُضبط هذا المتغير عبر إعدادات بيئة موقع Sites، **ولا يُحفظ في الكود أو GitHub**. يمكن وضع عدة عناوين مفصولة بفواصل. تسجيل الدخول وحده لا يمنح صلاحية الإدارة؛ يجب مطابقة البريد للقائمة المعتمدة.

## الحفظ على GitHub

ننصح بمستودع **Private** يحتوي على الكود والكتب المرفقة، مع الاحتفاظ بحقوق المؤلف. GitHub مخصص هنا لحفظ الإصدارات والتعاون وتاريخ التعديلات. **لا تعتمد على GitHub Pages لتشغيل المشروع الكامل**: قاعدة D1 وR2 وواجهات الإدارة تحتاج الخادم وبيئة Cloudflare/Sites.

قبل أي `git push` تأكد من عدم إضافة `.env`، أو بيانات تسجيل الدخول، أو ملفات مفاتيح خاصة. `.gitignore` يستبعد الملفات الحساسة والمجلدات المؤقتة والبناء الناتج.

## تحديث الموقع

الموقع المنشور متصل بمشروع Sites وله مستودع مصدره الخاص. دفع الكود إلى GitHub كنسخة ثانية **لا ينشر تلقائيًا** على الرابط الحالي. لتحديث الموقع المنشور، اتبع سير النشر الخاص بمشروع Sites واحفظ إصدارًا جديدًا من الكود نفسه.

## الحقوق

جميع النصوص والكتب والأغلفة وصورة المؤلف محفوظة الحقوق لـ**هاشم خالد شطير** وأصحاب الحقوق المعنيين. إتاحة القراءة والتحميل على موقعه لا تعني الترخيص بإعادة نشر المؤلفات أو إعادة استخدامها تجاريًا من مستودع الكود.


## توليد صفحات القراءة الواضحة

لمن ينزّل المشروع من GitHub لتشغيله محليًا: ملفات الكتب الأصلية موجودة في `public/books/`، أما صور صفحات القراءة فتُولَّد من تلك الكتب لتجنّب مشكلة تقطّع بعض الخطوط العربية في متصفحات الهواتف.

1. ثبّت **Poppler** (أداة `pdftoppm`) و**Python Pillow**.
2. من جذر المشروع شغّل: `python3 scripts/render-book-pages.py`
3. ستُنشأ صور الصفحات داخل `public/pages/`، ثم شغّل بناء المشروع المعتاد.

النسخة المنشورة على موقع Sites تتضمن جميع صور الصفحات الجاهزة. إذا عدّلت أحد ملفات PDF الأصلية، أعد توليد صور ذلك الكتاب باستخدام `--book` متبوعًا باسم مساره.
